# Python Assignment 3: Loops and Functions

## Overview

This assignment focuses on Python loops, control statements, and functions. It includes three programs designed to practice repetitive tasks, decision-making, and function definition.

## Programs

### 1. Number Guessing Game

A number guessing game developed using a `while` loop.

**Concepts Covered:**

* Random number generation using the `random` module and `randint()`
* `while` loop
* Conditional statements (`if`, `elif`, and `else`)
* Control statements (`break` and `continue`)
* `else` clause with a `while` loop
* User input and validation

**Description:**
The program generates a random number between 1 and 10. The user gets three attempts to guess the number. The program provides feedback if the guess is too high or too low. It also checks whether the guess is within the valid range. The game ends when the user guesses correctly or runs out of attempts.

### 2. Multiplication Table Generator

A program that generates the multiplication table for a number entered by the user.

**Concepts Covered:**

* `for` loop
* `range()` function
* User input
* Arithmetic operations
* Formatted output

**Description:**
The program accepts a number from the user and displays its multiplication table from 1 to 10. A `for` loop iterates through the numbers, calculates the products, and prints each result.

### 3. BMI Calculator

A program that calculates Body Mass Index (BMI) using a user-defined function.

**Concepts Covered:**

* Function definition using `def`
* Function parameters and arguments
* `return` statement
* User input
* Arithmetic operations
* Formatted output

**Description:**
The program accepts the user's weight in kilograms and height in meters. It uses the `calculate_bmi()` function to calculate BMI and displays the result rounded to two decimal places.

**Formula:**

BMI = Weight (kg) / Height (m)²

## Python Concepts Practiced

* Loops: `while` and `for`
* Conditional statements: `if`, `elif`, and `else`
* Loop control: `break` and `continue`
* Functions and return values
* Random number generation
* User input and output
* Arithmetic operations

## Learning Outcomes

* Understand how to use loops to repeat instructions.
* Apply control statements to manage program execution.
* Generate multiplication tables using the `range()` function.
* Define and call functions with parameters.
* Perform calculations and display formatted results.
