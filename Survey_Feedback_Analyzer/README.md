# Survey Feedback Analyzer Using Python

## Project Overview

The Survey Feedback Analyzer is a Python Fundamentals assignment that analyzes textual feedback collected through surveys.

The project uses a dictionary of lists to store feedback data and applies Python concepts such as loops, conditional statements, string operations, functions, sets, and sorting to clean and analyze the feedback.

## Objectives

* Store survey feedback using a dictionary of lists.
* Collect additional feedback from users.
* Clean text by removing punctuation and unnecessary spaces.
* Convert feedback text to lowercase.
* Count feedback entries containing specific words.
* Calculate the average rating.
* Identify the feedback with the highest word count.
* Extract unique words from all feedback entries.
* Sort feedback entries by rating in descending order.

## Dataset

The project starts with 10 preloaded feedback entries.

The dataset contains the following fields:

* `S_No` – Serial number
* `Name` – Name of the respondent
* `Feedback` – Written feedback
* `Rating` – Rating given by the respondent, from 1 to 5

Users can add additional feedback entries during program execution.

* `split()` and `join()`

## Project Workflow

1. Initialize the dataset with 10 feedback entries.
2. Collect additional feedback from the user.
3. Clean the feedback text.
4. Count feedback entries containing the words "good", "poor", and "excellent".
5. Calculate the average rating.
6. Identify the longest feedback by word count.
7. Extract and display unique words.
8. Sort feedback entries by rating from highest to lowest.

## Expected Outcomes

The program displays the cleaned feedback dataset, word-count insights, average rating, longest feedback, unique words, and feedback entries sorted by rating.

The exact results may vary depending on the additional feedback entered by the user.

## Learning Outcomes

This project provides practical experience in handling text data, processing lists and dictionaries, writing reusable functions, and extracting basic insights using Python.
