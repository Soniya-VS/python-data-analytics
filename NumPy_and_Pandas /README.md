# Python Data Analytics - NumPy and Pandas

## 📌 Project Overview

This project is part of Python Data Analytics . It focuses on learning and implementing fundamental data analysis techniques using NumPy and Pandas in Python.

The assignment covers numerical computations using NumPy arrays, data manipulation using Pandas Series, and data exploration using Pandas DataFrames.

The project uses temperature data, student marks, and transaction records to demonstrate the practical applications of these libraries.

## Topics Covered

### 1. NumPy Array Operations
- Creating 1D and 2D arrays
- Inspecting array properties
- Celsius to Fahrenheit conversion
- Maximum, minimum, and mean
- Array slicing and indexing

### 2. Pandas Series
- Creating a Series with custom indices
- Indexing using loc and iloc
- Boolean filtering
- Modifying and deleting values
- Calculating CGPA

### 3. Pandas DataFrame
- Creating a DataFrame
- Exploring rows, columns, and data types
- Filtering data
- Value counts and unique values
- Grouping data and calculating mean
- Adding, modifying, and deleting columns and rows
